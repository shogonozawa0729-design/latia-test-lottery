架空カードショップ抽選（カードボックス型）

LATIA 動作確認用の架空の抽選です。応募フォーム → 中継 → 完了（抽選番号・画面 URL の二次元コード）の流れを、構造だけ再現しています。実在の店舗・サービスの見た目・名称は使っていません。

応募フォーム（広告の動き）

  • 既定（ad=dom：スクロール中だけ広告枠の中身を入れ替え）
  • ad=style（広告枠の class だけ切り替え）
  • ad=afterinput（最初の入力の 20ms 後に 1 回だけ入れ替え）
  • ad=storm（200ms ごとに入れ替え続ける）
  • ad=off（何もしない）

その他の変種

  • aframe=0（隠れた補助フレームを追加しない・外部読み込みなし）
  • aframe=visible（同じ src の 300×80 表示フレーム）
  • item=2（応募する項目が 2 個）
  • relay=slow（中継ページを 1.5 秒見せる）

アプリを変えない完了確認用（実サイトの再現ではありません）

完了ページを /lottery/entry_complete/（form なし・入力欄なし）にした別シナリオです。実在のサイトの完了 URL・構造ではありません。

  • entry_complete に着くシナリオ

既定では応募フォームの読み込み約 1 秒後に、表示されない補助フレーム（www.google.com の reCAPTCHA aframe）を 1 個追加します。入力値は渡りません。
